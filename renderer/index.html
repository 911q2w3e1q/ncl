AI 报错分析


            

              
启用 AI 分析
游戏崩溃时自动调用 AI 分析原因并给出可一键应用的修复方案

              

                
              

            


            

              
AI 模式
「本地模型」使用启动器内置的小模型分析，完全离线、无需 API Key；「云端接口」使用你自己的 Key，质量更好

              

                

                  
                  
                

              

            


            

              
崩溃时自动分析
游戏异常退出后自动弹出分析结果；关闭后需在运行日志里手动点「分析报错」

              

                
              

            


            

              
本地模型
选一个内置小模型并下载到本地，之后分析完全离线运行，不消耗任何额度。内置的规则引擎会先给出确定性的崩溃结论，小模型输出作为补充意见

              

                

              

            


            

              
API 地址
兼容任何 OpenAI 格式接口，如 https://api.openai.com/v1、https://api.deepseek.com/v1、https://open.bigmodel.cn/api/paas/v4

              

                
              

            


            

              
API Key
只保存在本机设置文件，不会上传到任何第三方

              

                
              

            


            

              
模型
模型名称，如 gpt-4o-mini、deepseek-chat、glm-4-flash

              

                
              

            


            

              
测试连接
确认接口地址、Key 与模型可用

              

                
                
                
              

            


            

              
内容来源
下载页内容来自 Modrinth（免 API Key）与 BMCLAPI 镜像站（加速原版下载）。CurseForge 独占内容可用下载页工具栏的「导入本地文件」装入。
